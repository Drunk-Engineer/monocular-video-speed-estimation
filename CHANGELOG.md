## [1.0.0] - 2026-07-26

### Added

- Installable `monocular-speed` command-line interface.
- Full-view monocular-video preprocessing, training, inference, and evaluation.
- R3D-18 plus dilated temporal convolutional network model definition.
- Safe CPU-compatible checkpoint loading and release-asset download support.
- An anonymized training-source demonstration video, CSV, and GIF.
- Validation-only model and data documentation.
- CPU continuous integration for Linux and Windows.
