# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch. Older
research snapshots may not receive patches.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[odinswim1990@icloud.com](mailto:odinswim1990@icloud.com). Include:

- the affected version or commit;
- a minimal reproduction;
- the expected impact; and
- any suggested mitigation.

Do not include private recordings, personal data, credentials, or sensitive
location information in a public issue. Please allow a reasonable period for
triage before public disclosure.

This project is research software. A security report does not make the model
suitable for safety-critical vehicle control, law enforcement, or certified
measurement.
